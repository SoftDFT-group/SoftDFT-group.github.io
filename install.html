Install

Download and install

SoftDFT is a set of Julia source files. Install Julia, add a handful of registered packages, clone the repository, and run an input file.

Requirements

  • Julia 1.9 or later. Recent development and testing used Julia 1.11 and 1.13.
  • Windows, macOS or Linux. A laptop is enough for 1D calculations; 3D grids need more memory.
  • Git, to clone the repository (or download the ZIP from GitHub).
  • Optional: Python with NumPy and Matplotlib for the plotting scripts that ship with some examples.

1. Install Julia

The recommended installer is juliaup, which manages Julia versions:

# Windows (PowerShell)
winget install --name Julia --id 9NJNWW8PVKMN -e -s msstore

# macOS / Linux
curl -fsSL https://install.julialang.org | sh

2. Get the code

git clone https://github.com/gallegos-group/SoftDFT.git
cd SoftDFT

SoftDFT is currently used directly from source (it is not yet a registered Julia package), so the folder you clone is the installation.

3. Add dependencies

SoftDFT depends on a few registered Julia packages. The standard libraries LinearAlgebra, Printf and DelimitedFiles ship with Julia. Install the rest once, into a named environment:

julia --project=@softdft -e 'using Pkg; Pkg.add(["YAML", "FFTW", "LazyArrays", "LoopVectorization", "IterativeSolvers", "IterTools", "UnPack"])'

On Windows PowerShell, swap the quotes: -e "using Pkg; Pkg.add([\"YAML\", ...])", or start julia --project=@softdft and type the command at the julia> prompt.

4. Run a first calculation

Create a working folder with an input.yaml (for example the charged-slit input), then from that folder:

julia --project=@softdft
julia> include("/path/to/SoftDFT/src/iDFT/iDFT.jl")
julia> system = iDFT("input.yaml")

The first call compiles the code and can take about a minute; later runs in the same session are fast. Results are written to the current folder (see Outputs). For a bulk-only calculation, include src/iLST/iLST.jl and call iLST("input.yaml").

Check the final residual after every run. See Checking convergence.

Using VS Code

Install the Julia extension, open your working folder, start a Julia REPL from the command palette, and run the two lines above. Use cd("folder") in the REPL to change where output files are written.

Repository layout

src/
  molecular_system/   species, sequences, reactions, constants
  iLST/               bulk (homogeneous) Ising liquid-state theory
  geometry/           Cartesian grids and external fields
  iDFT/               inhomogeneous DFT: functionals, Coulomb, solver, analysis
  NonlinearSolvers/   Picard, Anderson mixing, continuation
routines/             helper scripts (pH and wall-separation series)
input.yaml            sample input
