Open-source classical density functional theory

Structure and thermodynamics of complex and confined fluids

SoftDFT is a modular Julia package for classical DFT of soft matter. It handles hard-sphere fluids, electrolytes, tethered and free polymers, and chemically responsive species whose charge states adjust to their local environment. Calculations run on 1D, 2D and 3D Cartesian grids with FFT-based convolutions.

What SoftDFT does

Classical DFT predicts equilibrium density profiles and thermodynamic properties of fluids near surfaces and in confinement by minimizing a grand-potential functional. It reaches the length scales of experiments at a small fraction of the cost of molecular simulation. SoftDFT is built on the Ising density functional theory (iDFT) framework. iDFT adds an internal-state variable to polymer DFT, so the ionization of each segment and the conformation of each chain evolve together under pH, salt and confinement.

molecular_system→iLST (bulk)→geometry→iDFT (inhomogeneous)
Free energies

Modular functionals

Ideal, modified fundamental measure theory, TPT1 chain connectivity, MSA electrostatic correlations and square-well attractions, combined by name in the input file.

 Chemistry

Reactions & charge regulation

General reaction schemes with pK values, a reservoir pH, multi-state species and ionizable surfaces whose charge is solved self-consistently.

 Geometry

1D, 2D and 3D grids

Cartesian slits and periodic boxes with hard, charged, square-well, point-charge, charge-regulated and user-supplied external fields.

Quick look

A calculation is described by one YAML file and run with one function call:

# input.yaml: weak polyacid brush at pH 7
procedure: iDFT
geometry:
  coordinate_system: Cartesian
  dimensions: [15.0]
  bin_width: [0.2]
  external_field:
    hard_walls: { dims: [1] }
species:
  - sequence: "AAAAAAAA"
    density: 0.0
    fixed: { density: 0.05, segment: [1], position: ["left"] }
  - { sequence: "c", density: 0.01, adjustable: true }
  - { sequence: "a", density: 0.01, adjustable: true }
  - { sequence: "Y", pSpecies: 7.0 }
  - { sequence: "Z" }
reactions:
  - { species: ["A", "Y", "B"], coeffs: [-1, 1, 1], pK: 4.756 }
  - { species: ["Y", "Z"], coeffs: [1, 1], pK: 14.0 }
model: [ideal, TPT1mfmt, TPT1msa]
julia> include("src/iDFT/iDFT.jl")
julia> system = iDFT("input.yaml")

The monomer and numerical blocks are omitted here; see the User Guide for the full input format and the complete example.

Project

Goals

SoftDFT aims to be a general-purpose, open and reproducible platform for 3D classical DFT. The planned work consolidates the equilibrium engine behind a geometry-aware coordinate-system layer, builds a validated benchmark gallery, and adds parameter-continuation, phase-equilibrium and time-dependent (dynamic DFT) workflows.

Community

Source code, documentation, tutorials and example workflows are released openly. Questions, bug reports and feature requests are welcome through GitHub Issues. Workshops and course modules are planned.
