The theory behind SoftDFT and how to cite the software.

Citing SoftDFT

If you use SoftDFT in published work, please cite the software and the Ising DFT papers relevant to your calculation.

A. Gallegos, SoftDFT: A Julia-based platform for modeling soft matter with
Ising density functional theory, version 0.1.0 (2025).
https://github.com/gallegos-group/SoftDFT
BibTeX 
@software{softdft,
  author  = {Gallegos, Alejandro},
  title   = {{SoftDFT}: A Julia-based platform for modeling soft matter with
             Ising density functional theory},
  version = {0.1.0},
  year    = {2025},
  url     = {https://github.com/gallegos-group/SoftDFT},
  license = {MIT}
}

The repository includes a CITATION.cff file, so GitHub's “Cite this repository” button gives the same entry. Versioned releases with DOIs are planned.

  2. A. Gallegos, M. Müller, J. Wu. Single-chain simulation of Ising density functional theory for weak polyelectrolytes. J. Chem. Phys. 159, 214902 (2023). doi:10.1063/5.0175561
