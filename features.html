Features

What SoftDFT can model

Capabilities of the current release, taken from the source code. Items under “In development” are planned and not yet available.

Architecture

SoftDFT is written in Julia and organized as four modules that run in sequence. Each one can be extended without editing the others.

molecular_system→iLST→geometry→iDFT

molecular_system

Parses species, chain sequences and topology, monomer properties, reactions and system constants (temperature, dielectric constant, length scale, Bjerrum length).

iLST: bulk state

Ising liquid-state theory for the homogeneous reservoir: bulk densities, charge balance, reaction equilibria, chemical potentials and pressure.

geometry

Builds the Cartesian grid (1D, 2D or 3D) and the external fields acting on each monomer type.

iDFT: inhomogeneous solve

Sets up density fields, Fourier caches, functionals and the Coulomb solver, then solves the Euler–Lagrange equations and writes the analysis files.

Free-energy functionals

Excess free-energy terms are registered by name and selected in the model list of the input. The same names are used for the bulk (iLST) and inhomogeneous (iDFT) parts.

KeyContribution
idealIdeal-gas (and ideal-chain) free energy
mfmtModified fundamental measure theory for hard-sphere excluded volume (mixtures of arbitrary diameters)
TPT1mfmtmFMT plus first-order thermodynamic perturbation theory for chain connectivity
msaMean-spherical-approximation electrostatic correlations
TPT1msaMSA correlations with TPT1 chain contribution
swSquare-well short-range attraction between monomer pairs (defined in pairs)

Long-range electrostatics are handled separately by a Coulomb solver. It is set up automatically when the system contains charges, so coul is not listed under model.

Molecules, reactions and charge regulation

  • Arbitrary sequences. Each species is a string of monomer labels (e.g. "AAAAAAAA", "c"), modelled as freely jointed tangent-bead chains or single beads.
  • Grafted chains. A fixed block tethers a chosen segment to a wall at a given grafting density, for polymer brushes.
  • Reactions. Any number of reactions with stoichiometric coefficients and pK values. Species may carry several internal states: the Ising variable of iDFT.
  • Reservoir pH and p-values. pSpecies fixes a species' activity (e.g. the proton species Y sets the pH). adjustable species are tuned to keep the bulk electroneutral.
  • Charge-regulated surfaces. Walls carrying acidic or basic sites whose charge responds to the local electrostatic potential. The wall charge is mixed with the density fields and solved self-consistently.

Geometry and external fields

Cartesian grids in one, two or three dimensions. Box lengths and bin widths are set per dimension; lateral directions are periodic. External fields act per dimension on the two bounding walls.

FieldPurpose
hard_wallsImpenetrable planar walls
charged_wallsFixed uniform surface charge on each wall
charge_regulated_wallsIonizable acid/base surface sites with pKa and site density
sw_wallsSquare-well wall attraction, set per monomer type
pointcharge_wallsDiscrete point charges on a wall
input_externalArbitrary user-supplied potential read from a file (1D–3D)

Electrostatics

  • FFT Poisson solver (default): the potential from mobile ions and wall charges, with a neutrality (Donnan) shift.
  • Half-space solver (optional, 1D, electrostatics: {solver: half_space}): a charged wall facing a semi-infinite reservoir, with a field condition at the wall and zero potential far away.

Numerical solvers

  • Picard mixing with automatic switch to Anderson mixing below a residual threshold.
  • Pseudo-arclength continuation for tracing solutions through parameter changes, including grafting density.
  • Routines for adjusting pH and wall separation along a series of calculations.
  • Damping, mixing limit, Anderson depth, tolerance and iteration cap are all set in the input.

Outputs

Each run writes plain-text results to the working directory: density profiles by monomer (rho_beads_K.txt) and segment (rho_segments_*.txt), the electrostatic potential (MEP.txt), grand potential, contact-value-theorem check (cvt.txt), brush height, and state-fraction and degree-of-dissociation profiles for reactive chains.

In development

These capabilities are planned and are not in the current code.
  • A unified CoordSystem layer so the same solver runs on Cartesian, cylindrical and spherical geometries.
  • A documented template for adding new functionals without touching solver internals.
  • An automated benchmark and regression suite run under continuous integration.
  • Parameter-scan, phase-equilibrium and transition-path workflows.
  • Time-dependent (dynamic) DFT and coupling to transport.
  • GPU execution and versioned, DOI-tagged releases.
