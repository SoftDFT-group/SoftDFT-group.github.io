Workflow

Every calculation is described by a single YAML file. Calling iDFT("input.yaml") runs four stages:

  1. Molecular system: species, sequences, monomers, reactions and constants are parsed.
  2. Bulk state (iLST): the reservoir is solved for densities, reaction equilibria, charge balance, chemical potentials and pressure.
  3. Geometry: the grid and the external fields are built.
  4. Inhomogeneous DFT: the density profiles are solved iteratively and the analysis files are written.

The returned object holds everything: system.fields, system.geometry, system.bulk_system, system.functionals and system.coulomb.

Units

  • Lengths are in reduced units of l_sc (default 0.5 nm, set with reduced_units: {l_sc: 0.3} in nm). A monomer diameter of 1.0 is one l_sc.
  • density is a number density in particles per l_sc3; concentration is in mol/L. Use one or the other for each species. Conversion: ρ = c × 0.602214 × (l_sc in nm)3.
  • Surface charge and site density are in elementary charges per l_sc2. For example, 0.02 C/m2 with l_sc = 0.3 nm is 0.02 × (0.3×10−9)2/e = 0.01123.
  • Energies are in kBT; potentials in output files are reduced, βeψ.

procedure

iDFT for an inhomogeneous calculation. A bulk-only calculation uses the same file with iLST("input.yaml"); the geometry block is then ignored.

geometry

geometry:
  coordinate_system: Cartesian
  dimensions: [16.0]          # box length per dimension (l_sc); 1, 2 or 3 entries
  bin_width: [0.1]            # grid spacing per dimension
  external_field: { ... }     # see below

In 2D and 3D, directions without walls are periodic. Grid spacing controls accuracy: contact values and segment amounts converge roughly quadratically and linearly with spacing respectively (see the density-sweep and segment-conservation examples).

external_field

Each field names the dimensions it acts on with dims. Per-wall values are given as [left, right]; with several dimensions, give one such pair per dimension.

external_field:
  hard_walls:
    dims: [1]
  charged_walls:
    dims: [1]
    charge: [-0.01, 0.01]           # e / l_sc^2
  charge_regulated_walls:
    dims: [1]
    site_density: [0.02, 0.02]      # ionizable sites per l_sc^2
    kind: [acid, base]
    pKa: [7.0, 7.0]
    # pH is taken from a proton species (Y, H or H+) with pSpecies;
    # give pH: here only if the input has no proton species
  sw_walls:
    dims: [1]
    monomers:
      A:
        energy: [[-2.0, 0.0]]       # k_BT, left/right wall
        lambda: [[1.5, 1.5]]        # range, in units of the monomer radius
  • charged_walls and charge_regulated_walls may be combined; the charges add.
  • For acid sites, log[α/(1−α)] = ln10·(pH−pKa) + βeψwall and the wall charge is −Γα. For base sites the signs reverse and the charge is +Γα. The regulated charge is uniform over each wall.
  • pointcharge_walls places discrete charges on a wall (dims, charge).
  • input_external reads a potential from a CSV of grid indices and values (dims, file). It is experimental; see the 3D patterned-field example.

species

species:
  - sequence: "AAAAAAAAAA"        # a 10-bead chain of monomer A
    density: 0.0
    fixed:                        # grafted chain (brush)
      density: 0.05               # chains per l_sc^2
      segment: [1]
      position: ["left"]
  - sequence: "c"                 # cation
    density: 0.01
    adjustable: true              # may be tuned to keep the bulk neutral
  - sequence: "a"
    concentration: 0.1            # mol/L instead of density
  - sequence: "Y"                 # proton
    pSpecies: 7.0                 # fixes -log10 activity, i.e. the pH
  - sequence: "Z"                 # hydroxide

A species with a fixed block must have zero bulk density. Species that appear only through reactions (such as the ionized state B below) are not listed here.

reactions

reactions:
  - species: ["A", "Y", "B"]      # A  <=>  Y + B   (acid dissociation)
    coeffs: [-1, +1, +1]
    pK: 4.756
  - species: ["Y", "Z"]           # water: 0 <=> Y + Z
    coeffs: [+1, +1]
    pK: 14.0

Negative coefficients are reactants and positive ones products. Several reactions can share species, so multi-step equilibria and multi-state monomers are possible.

monomers

monomers:
  A: { diameter: 1.0, valence: 0.0 }
  B: { diameter: 1.0, valence: -1.0 }
  c: { diameter: 1.0, valence: +1.0 }
  a: { diameter: 1.0, valence: -1.0 }
  Y: { diameter: 1.0, valence: +1.0 }
  Z: { diameter: 1.0, valence: -1.0 }

Every label used in a sequence or reaction needs an entry. Diameters may differ between monomers.

pairs

Pair parameters for the square-well functional (sw in model):

pairs:
  square_well:
    A, A: { energy: 0.5, lambda: 1.5 }
    A, B: { energy: 0.2, lambda: 1.5 }

constraints

constraints:
  temperature: 298.15            # K   (default 298.15)
  dielectric_constant: 78.4      # (default 78.4)
Temperature and dielectric constant are read from the constraints block. A block named system is not read, and the defaults above apply.

model

model:
  - ideal
  - TPT1mfmt     # or mfmt for unbonded beads
  - TPT1msa      # or msa
  - sw           # if pairs.square_well is given

Available keys: ideal, mfmt, TPT1mfmt, msa, TPT1msa, sw. Do not list a Coulomb term; electrostatics are added automatically for charged systems.

electrostatics (optional)

electrostatics:
  solver: half_space   # default is the FFT solver (coul)

The half-space solver is 1D only. It accepts a fixed or regulated charge on the left wall and requires an uncharged right wall, which stands for a distant reservoir.

numerical

KeyMeaningDefault
toleConvergence tolerance on the residual1e-6
max_itersMaximum iterations100000
dampingPicard mixing fraction0.5
mixing_maxUpper bound on the mixing coefficient1.0
switch_toleResidual below which Anderson mixing starts1e-2
andermAnderson memory depth5

Charged and reactive systems usually need small mixing, e.g. damping: 0.01, mixing_max: 0.01, and sometimes an earlier Anderson switch (switch_tole: 0.1). Continuation runs also read ds_init, ds_min, ds_max, num_keep and gamma.

Outputs

Files are written to the current working directory:

FileContents
rho_beads_K.txtDensity profile of each monomer type on the grid
rho_segments_<seq>.txtDensity of each segment of a chain
MEP.txtReduced electrostatic potential βeψ
grand_potential.txtGrand potential of the inhomogeneous system
cvt.txtContact-value-theorem check at each wall
brush_height.txtBrush height for grafted chains
state_fraction_*.txt, total_state_fractions_*.txtIonization state of reactive chains, per segment and averaged
error_log.txtSolver residual history

Checking convergence

The solver returns when the residual drops below tole or when it reaches max_iters. In the second case it still prints a completion message. Before using a result:

  • check the final residual in error_log.txt, or recompute it from the returned fields (the charge-regulated example shows how);
  • if the residual oscillates, lower damping and mixing_max and raise max_iters;
  • refine bin_width until the quantities you report stop changing.

Extending SoftDFT

Functionals, bulk models and Coulomb solvers are looked up in registries, so a new term is added by writing its type and methods and registering a key:

# src/iDFT/functionals/Abstract_Types/functional_registry.jl
include("../short_range_interactions/my_term.jl")
register_functional(:my_term, MyTermFunctional)

# src/iLST/free_energy/Abstract_Types/model_registry.jl
register_model(:my_term, MyTermFreeEnergy)

The new term then becomes available as model: [..., my_term]. Use the existing mfmt.jl and square_well.jl files as templates. A step-by-step developer guide is in preparation.
